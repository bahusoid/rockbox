**Audiobook Playback & Settings**

The latest release includes an enabled audiobook profile.

**IMPORTANT**
Copy your audiobooks to the **Audiobooks** (or **ABooks**) folder.
Add your own audiobook/podcast folders via *General Settings -> Alt Settings -> Alt Settings -> Yes* (this will open the folder selection).

**What it includes:**
* When listening to audiobooks, the Next/Prev buttons act as 30-second skips (configurable). For music, standard track skipping applies.
* Playback speed automatically resets when switching from audiobooks to music.
* Recent bookmarks and auto-bookmarking upon stopping playback are enabled for audiobooks.
  * i.e., **Recent Bookmarks** in the **Main Menu** only keeps the latest bookmark for each folder. To view all bookmarks for a specific folder, open its latest bookmark, then navigate to *WPS Context Menu -> Bookmarks -> List Bookmarks* — all bookmarks for that folder will be displayed there.
  * Quickest way to make a bookmark is to stop playback (long-press on-screen pause button, or double long Power press)
* Skip Length adjustment for audiobooks has been added to the Quickscreen (top/bottom).
* Locking the device turns off the screen instantly while media buttons remain active.
* Rewind across tracks is enabled (skipping to the end of the previous track).
* CUE support is enabled.

**To view chapters in M4B files:**
Open the context menu for the M4B file -> *Open with...* -> *mp4chapters_to_cue*. A .cue file with the book's chapters will be generated next to the file.

**Other useful settings:**
* **Sleeptimer:** Can be enabled via *Settings -> General Settings -> Startup/Shutdown -> Start Sleep Timer*. Related settings such as `Start Sleep Timer On Boot`, `Keypress Restarts Sleeptimer`, and `Default Sleep Timer Duration` can also be found here.
* **Start Screen:** Configured via *Settings -> General Settings -> Startup/Shutdown -> Start Screen*.
* **Autolock:** To automatically lock the device when the screen turns off, tick 'Autolock' in *Settings -> General Settings -> System -> Advanced Key Lock -> Settings*.
* **Auto-Change Directory:** Can be enabled via *Settings -> Playback Settings -> Auto-Change Directory*.
* **Single Mode:** Pauses playback when a track/folder is changed (depending on the settings). See *Settings -> Playback Settings -> Single Mode*.
* **Backlight Exemptions:** Useful if you don't want to lock the device but still want to keep the screen off during button presses. See *Settings -> General Settings -> Display -> LCD Settings -> Backlight Exemptions*.
* **Touchscreen Exemptions:** You can disable the touchscreen completely in the WPS and/or Menus/Lists. This is recommended if you exclusively use button navigation. See *Settings -> General Settings -> Display -> Touchscreen Settings -> Touchscreen Exemptions*.
